title: "关系从句：说明你指的是哪一个"
description: "区分限定与补充信息，掌握关系词与省略条件。"
---

## 把两个信息合成一个名词短语

**The file is missing. You uploaded the file yesterday.** → **The file that you uploaded yesterday is missing.** 从句告诉读者是哪份文件。

| 关系词 | 常见关联 | 示例 |
| --- | --- | --- |
| who / whom | 人；whom 较正式，作宾语 | the colleague who helped me |
| which | 物，也可指前面整件事 | the tool which we tested |
| that | 限定性从句中的人或物 | the file that failed validation |
| whose | 所属关系 | a user whose account was locked |
| where / when | 地点 / 时间关系 | the room where we met |

## 逗号改变信息地位

**My colleague who works in Berlin called.** 用从句识别是哪位同事。

**Maya, who works in Berlin, called.** 对已经识别的 Maya 补充信息。非限定性从句通常不用 that，也不能照同样方式省略关系词。

## 什么时候可以省略

限定性从句中，关系代词充当宾语时常可省略：the file (that) I uploaded。作主语时不能如此省略：the file that contains the logs。不要变成 the file contains the logs 来充当同一个完整名词短语。

where 不能替代所有含地点名词的关系：the city where I work（在那座城工作）；the city that I visited（visit 直接接城市作宾语）。要看从句缺什么。

## 避免重复宾语

the tool that I use **it** 多出了 it。that 已与 use 的宾语位置关联，不要又重复放一个代词。

## 练习

1. 改错：This is the file that I uploaded it.
2. “The person ___ called is my manager.” 可否省略关系词？
3. 合并：We chose the solution. The solution was easier to maintain.

<details><summary>答案与解释</summary>

1. This is the file that I uploaded. 或 This is the file I uploaded.
2. 不能按宾语省略规则省略，关系词在从句中作主语。
3. We chose the solution that was easier to maintain.

</details>
