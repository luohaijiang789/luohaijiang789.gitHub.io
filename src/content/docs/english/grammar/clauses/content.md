## 先区分“连接两句”和“把一句嵌进去”

**The test passed, but the deployment failed.** 两个分句并列，but 表示转折。

**I know that the deployment failed.** that 引导的内容整体充当 know 的宾语。不能因为中文停顿，就用一个逗号把两个独立英文句子随意接起来。

| 关系或角色 | 常见结构 | 例子 |
| --- | --- | --- |
| 补充、转折、结果 | and / but / so | I checked it, and Maya confirmed it. |
| 陈述内容 | that 从句 | I think that it will work. |
| 未确定的选择 | whether / if 从句 | We need to know whether it is ready. |
| 已知或未知的信息 | what / why / how 等 | I understand why it failed. |
| 用从句作主语 | 常用形式主语 it | It is clear that we need more tests. |

## what 与 that 的区别

**I know what you need.** what 本身在从句中承担 need 的宾语，意为你需要的东西。

**I know that you need help.** 从句 you need help 的基本结构已完整，that 主要引入陈述内容。不要写 I know that you need 来表达“我知道你需要什么”。

## whether 与 if 不是任何位置都可互换

一般宾语从句里常可用两者表达“是否”；介词之后、whether to do 等结构通常用 whether：We talked about whether to continue。遇到复杂位置时优先核对结构。

## 写长句前先写短句

先把事实分开：The request failed. The token had expired. 再明确关系：The request failed because the token had expired。不要为了显得高级一次堆入多个未说明的逻辑关系。

## 练习

1. 选择：I don't know ___ he wants.（what / that）
2. 修改：We discussed about if to continue.
3. 用 but 连接“测试通过了”和“我仍有疑问”。

<details><summary>答案与解释</summary>

1. what，承担 wants 的宾语。
2. We discussed whether to continue. discuss 通常直接接宾语；如果用 talked，则可说 talked about whether to continue。
3. The test passed, but I still have questions.
