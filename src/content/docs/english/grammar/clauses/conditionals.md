## 连接词让读者看见关系

because 给原因，although / though 表让步，when / while / before / after 表时间，if / unless 表条件。**Although it is expensive, it saves time.** 不必再机械加 but 连接同一个结构。

| 条件视角 | 常见形式 | 例子 |
| --- | --- | --- |
| 一般规律 | if + 现在，主句现在 | If a token expires, the request fails. |
| 未来开放条件 | if + 现在，主句 will/can 等 | If it passes, we'll deploy it. |
| 与当前事实有距离的假设 | if + 过去式，would + 原形 | If I had more time, I would test it again. |
| 对过去的反事实假设 | if + had done，would have done | If we had tested it, we would have found the bug. |

这些常见模式帮助学习，不涵盖所有真实条件句。过去式在假设里可以表达距离，而不是真的把事件放在过去。

## 混合条件要看两段各自的时间

**If I had accepted that job, I would live in Berlin now.** 过去未实现的条件，影响当前结果。不要强迫 if 与结果必须处于相同时间。

unless 常意为“除非 / 如果不”：We won't proceed unless it passes。不要无意中再次添加否定，改变所需意思。

## wish 与希望发生不同

**I wish I had more time.** 对当前事实的遗憾。**I wish I had checked it.** 对过去的遗憾。**I hope it works.** 希望一个仍可能发生的结果。形式与表达立场不同。

条件从句里通常不用 will 简单表达未来，但 will 可以表示意愿等特殊意义。先掌握普通条件，再在实际例句中研究例外。

## 练习

1. 真实的未来条件：If it ___ (rain), we'll stay inside.
2. 对过去遗憾：“如果我检查过，就会发现错误。”
3. 改错：Although it is useful, but it is expensive.

<details><summary>答案与解释</summary>

1. rains。这个条件从句用现在形式。
2. If I had checked it, I would have found the error.
3. Although it is useful, it is expensive. 或 It is useful, but it is expensive.
