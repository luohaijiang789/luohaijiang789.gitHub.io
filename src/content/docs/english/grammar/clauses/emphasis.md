## 普通语序已经可以表达多数工作需求

先准确写出 **I found the problem in the logs.** 再根据需要突出部分信息：**It was in the logs that I found the problem.** 强调句改变焦点，不会凭空增加证据。

| 结构 | 例句 | 用途与边界 |
| --- | --- | --- |
| it 强调 | It was Maya who found it. | 突出人物或其他成分 |
| what 分裂句 | What we need is more evidence. | 先建立话题，再给重点 |
| 否定性成分前置 | Never have I seen this error. | 较强调或书面，出现助动词倒装 |
| so / neither 附和 | So do I. / Neither do I. | 与前句助动词、肯否定匹配 |
| there 存在结构 | There is a problem. | 引入新对象，不等于地点 there |
| 省略 | I can help, and Maya can too. | 被省略内容应可由上下文恢复 |

## 倒装不能随处套

Only after the test **did we notice** the issue：前置限制成分引发这里的倒装。Only Maya noticed the issue 中 only 修饰主语，不按同样方法倒装。强调功能与句法位置都要看。

If I had known 的较正式替代可以是 Had I known。它适合识别与较正式表达，不是日常每句话都要使用的形式。

## 读长句的顺序

找限定谓语 → 找主语 → 暂时拿开插入语和修饰 → 判断是否倒装或省略 → 恢复普通顺序验证意思。遇到 “Not only did…” 先找助动词后面的主语，而不是把 did 当成额外动作。

## 练习

1. 用 What we need is… 说明你需要更多测试。
2. “I can explain it.” 附和“我也能”，用 So do I 还是 So can I？
3. 修改 “Only Maya did find the bug” 若本意只是中性地说只有 Maya 找到了。

<details><summary>答案与解释</summary>

1. What we need is more testing / more tests. 选择看你指测试活动还是测试项。
2. So can I，要匹配 can。
3. Only Maya found the bug. did 可用于特定强调语境，但不是因 only 修饰主语而必须添加。

</details>
