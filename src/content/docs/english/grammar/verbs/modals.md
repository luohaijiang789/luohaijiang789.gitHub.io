## 情态词后的形式

can、could、may、might、must、should、will、would 后通常接动词原形，不加第三人称 -s：She can help。ought to、have to 等结构形式不同，要连同整体记。

| 功能 | 常见表达 | 注意 |
| --- | --- | --- |
| 能力 | can / could / be able to | could 不只是过去，也可委婉请求 |
| 许可与请求 | Can/Could/May I…? | 正式程度与人际关系影响选择 |
| 建议 | should / ought to | 比命令更适合讨论建议 |
| 义务 | must / have to | 使用差别取决于来源、语境和表达重点 |
| 可能性 | may / might / could | 不要强行换算固定百分比 |
| 较有把握的推断 | must be / can’t be | 推断依据要明确 |

## 必须分清：mustn't 与 don't have to

**You mustn't share this password.** 禁止分享。

**You don't have to share it.** 没有必要分享，不是禁止。

needn't 也可表达没有必要。谈过去没有必要且已经做了的事，可以遇到 needn't have done；谈一般过去的必要性可用 didn't need to，具体是否实施依赖语境。

## 对过去作推测

must have done：根据现在掌握的信息推断过去很可能发生；might have done：可能发生；can't have done：认为不可能发生。不要把 must have done 当成普通的过去义务；过去义务通常用 had to。

## 把态度说准确

“这个方案可能有效”可以说 It might work；“你应该先测试”是 You should test it first。一个是可能性，一个是建议。不要只因为中文都像“应该”就混用。

## 练习

1. “不必周末工作”用 mustn't 还是 don't have to？
2. 改错：She can explains it.
3. 你只掌握部分证据，如何避免把假设说成结论？

<details><summary>答案与解释</summary>

1. You don't have to work at the weekend. 表达没有义务；具体措辞依工作安排。
2. She can explain it.
3. 例如 It might be a configuration issue. We need to check the logs. 用可能性加验证行动。
