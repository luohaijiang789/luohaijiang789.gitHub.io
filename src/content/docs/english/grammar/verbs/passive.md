## 换信息中心，不是只换几个词

主动：**The policy gate blocked the request.** 从执行者说起。

被动：**The request was blocked by the policy gate.** 从请求的遭遇说起。报告结果、执行者未知或不重要时，被动很常见；需要明确责任时，不应为了模糊执行者而滥用。

| 形式 | 示例 |
| --- | --- |
| 一般现在 | The token is checked. |
| 一般过去 | The request was blocked. |
| 正在进行 | The issue is being investigated. |
| 现在完成 | The issue has been fixed. |
| 情态 | The result must be verified. |
| 将来 | The report will be reviewed. |

基本结构是 **be + 过去分词**，时间与体主要体现在 be 的组合中。不是每个过去分词前随便补 is 就能得到所需形式。

## 哪些不能直接照搬

不及物动词没有相同意义下的直接宾语可转为主语：The accident happened 不能机械改成 The accident was happened。某些固定结构和介词动词可形成自己的被动用法，要看具体搭配。

过去分词也可能像形容词描述状态：The door is closed。句子是强调关门动作还是关闭状态，需要结合上下文。get 被动如 got delayed 更偏一些口语用法，语气与搭配不同。

## by 与工具、方式

by 常引入执行者：written by Maya。工具可用 with：opened with a key。传输方式等还有 by email 等固定搭配，不要把所有 by 都理解成被动执行者。

## 练习

1. 把 “We are reviewing the report.” 改为以 report 开头。
2. 区分 “has been fixed” 与 “is being fixed”。
3. 改错：The outage was happened yesterday.

<details><summary>答案与解释</summary>

1. The report is being reviewed (by us).
2. 前者表示到现在已有修复结果；后者表示修复正在进行。
3. The outage happened yesterday. happen 在此不按该方式被动化。

</details>
