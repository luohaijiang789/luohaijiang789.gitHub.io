## 三个层次

**The server stopped.** 报告发生了什么。**We were deploying an update when it stopped.** 提供当时的进行背景。**We had changed the configuration before the failure.** 把某次更早变化放在过去参照点之前。

| 视角 | 结构 | 示例 |
| --- | --- | --- |
| 过去的完成事件或状态 | 过去式 | I checked the logs yesterday. |
| 过去某时进行 | was/were + -ing | I was checking the logs at ten. |
| 过去参照点之前 | had + 过去分词 | I had checked them before the meeting. |

过去进行不等于“动作时间很长”；一般过去也不等于“动作很短”。选择取决于你如何呈现事件。

## 不规则动词与助动词

| 原形 | 过去式 | 过去分词 |
| --- | --- | --- |
| go | went | gone |
| see | saw | seen |
| write | wrote | written |
| make | made | made |
| take | took | taken |
| read | read /red/ | read /red/ |
| be | was/were | been |

一般过去疑问和否定通常用 did + 原形：Did you see it? / I didn't see it. 不能写 Did you saw it?；be 的过去形式直接构成 Was it ready?

## 过去完成不是“先发生就必须用”

当上下文、时间或 before/after 已清楚表达顺序时，未必需要每个较早动作都使用过去完成。它用于把注意力明确放到过去参照点之前，避免时间关系不清。

## 练习

1. 改错：I didn't went to the meeting.
2. 为 “I was writing when…” 补一个打断事件。
3. 解释 “When I arrived, the meeting had started.” 的先后。

<details><summary>答案与解释</summary>

1. I didn't go to the meeting.
2. 例如 I was writing when the alarm rang. writing 是进行背景，rang 是插入事件。
3. 会议开始在先，我到达在后。

</details>
