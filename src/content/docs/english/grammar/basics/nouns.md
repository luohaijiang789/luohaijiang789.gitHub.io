## 名词前面为什么经常少不了一个词

可数单数名词通常需要限定词：**a file、the file、my file、this file**。不能把 “I opened file” 当成一般完整用法；需要说明是一个文件、已知文件或自己的文件。

| 判断 | 常见选择 | 示例 |
| --- | --- | --- |
| 一个、不特定的可数对象 | a / an | I found a problem. |
| 双方能识别的对象 | the | The problem is in this function. |
| 归属或指示 | my / this / that 等 | Please open my file. |
| 泛指复数或不可数概念 | 常用零冠词 | Computers need electricity. |

a / an 看紧随其后的**声音**：a user，an hour，an important issue。不是机械地看字母是不是 a/e/i/o/u。

## 可数性取决于当前意义

information、advice、equipment 在常见含义下通常不可数：some information、a piece of advice、two pieces of equipment。coffee 可指饮品，也可用 two coffees 表示两杯；不能根据中文“能不能数”直接判断。

some 常用于肯定句，也可用于期望肯定回答的请求或提议；any 常见于疑问、否定，也可表示“任何一个”。much 常配不可数，many 常配可数复数；a lot of 两者都能搭配。

## 代词与指代要对上

I / me / my / mine：主格、宾格、物主限定词、物主代词。**This is my report. The report is mine. Send it to me.** its 表示所属，it's 是 it is 或 it has 的缩写。

a few 表示有一些；few 倾向强调很少、几乎没有。a little 与 little 对不可数表达相近对比。another 通常表示另一个；the other 常指明确剩余的另一个；others 可以独立表示其他一些对象。

## 练习

1. a user / an user 选哪个？
2. 修改 “I need an advice and two equipments.”。
3. “I found a file. ___ file contains logs.” 应选什么？

<details><summary>答案与解释</summary>

1. a user，user 起始声音为 /j/。
2. I need some advice and two pieces of equipment. 具体单位也可以按实际物品名称表达。
3. The，前一句引入了当前可以识别的文件。

</details>
