## 先找到“谁，做什么”

**The application checks permissions before execution.** 主语是 The application，谓语动词是 checks，宾语是 permissions，before execution 修饰发生时间。先识别主干，再处理附加信息。

“名词、动词、形容词”是词类；“主语、宾语、定语”是成分。同一个名词短语在不同句子里可以承担不同成分；一个从句也能充当主语或宾语。

| 结构 | 原创例句 | 判断重点 |
| --- | --- | --- |
| 主语 + 不及物动词 | The server crashed. | 不直接接宾语 |
| 主语 + 及物动词 + 宾语 | We fixed the issue. | fixed 的对象是 issue |
| 主语 + 系动词 + 表语 | The result is reliable. | reliable 描述主语状态 |
| 主语 + 动词 + 双宾语 | She sent me a message. | me 是接收者，message 是内容 |
| 主语 + 动词 + 宾语 + 宾补 | We found the task difficult. | difficult 描述 task |

这些是分析工具。不同语法体系可能采用不同分类，不必把每个真实句子硬塞成一种孤立标签。

## 修饰语放在哪里

**a useful tool**：形容词修饰名词。**work carefully**：副词修饰动作。**the file on the server**：介词短语限定 file。**the file that you uploaded**：关系从句限定 file。

**be 不是万能连接词。** “I am work here” 不成立；表达通常的工作地点，用 I work here；描述正在工作，用 I am working；描述职业身份，用 I am an engineer。

祈使句常省略主语 you：Check the logs. 陈述句里的主语通常不能按中文习惯随意省掉；“很方便”应根据所指说 It is convenient，而不是只写 Is convenient。

## 练习

1. 找出 “The policy made the request invalid.” 的宾语和宾补。
2. 修改 “I am understand the problem.”。
3. 用三个结构分别描述你的工作、一个工具和一次问题。

<details><summary>答案与解释</summary>

1. the request 是宾语，invalid 是宾补，描述请求的状态。
2. I understand the problem. understand 在此用一般现在式；不用在前面随意加 am。
3. 参考：I analyse logs. / The tool is useful. / The service stopped. 对象与内容应换成自己的实际情况。

</details>
