## 词根索引应该怎样用

词根帮助你建立联系和记忆，但不能保证从字面直接算出现代含义。下表是常见的历史来源线索；不同变体、借入路径与语义变化需要查具体词源。

| 线索 | 核心联系 | 用来建立联系的词 |
| --- | --- | --- |
| spect / spec | 看 | inspect、spectator |
| dict / dic | 说 | predict、dictate |
| port | 搬运、携带 | transport、portable |
| scrib / script | 写 | describe、manuscript |
| struct | 建造 | construct、structure |
| tract | 拉 | attract、extract |
| ject | 投、扔 | inject、reject |
| mit / miss | 送、放出 | transmit、mission |
| cred | 相信 | credible、credibility |
| vis / vid | 看 | visible、video |
| aud | 听 | audio、audible |
| phon | 声音 | telephone、phonetic |
| graph | 写、记录 | biography、autograph |
| bio | 生命 | biology、biography |
| geo | 地球、土地 | geology、geography |
| therm | 热 | thermal、thermometer |
| micro / macro | 小 / 大 | microscope、macroeconomic |
| tele | 远 | telephone、telecommunication |
| auto | 自己 | autobiography、automatic |
| chron | 时间 | chronological、chronology |

这些不是允许任意组合的英文积木。也不意味着同样的字母串在所有单词里都属于这个词根。

## 三个经过具体词源核对的例子

**inspect**：来源涉及 in- 与 specere（看），可联系向内仔细看。现代常用义是检查，搭配 inspect the logs。

**predict**：来源涉及“预先”与“说”，现代可指根据依据预测，搭配 predict a failure。不能把它误当成保证。

**transport**：来源涉及 trans- 与 portare（携带），现代常见运送与运输的含义，搭配 transport equipment。

这些简化说明分别可核对 [inspect](https://www.merriam-webster.com/dictionary/inspect)、[predict](https://www.merriam-webster.com/dictionary/predict)、[transport](https://www.merriam-webster.com/dictionary/transport) 的 Word History。

## 不该这样记

把一个熟悉的中文谐音当成真实词源；为每个词硬拆；根据根义拒绝接受现代义；忽略词性和搭配。联想可以自创，但必须写明它只是记忆线索。

## 练习

1. 为 portable、audible、visible 找到相关线索，再查词典确认当前义。
2. 为什么知道 port 与携带有关，还不能把所有 port 都解释成搬运？
3. 用 inspect 或 predict 造一句自己工作中可能使用的话。

<details>
<summary>答案与解释</summary>

1. 分别可联系携带、听、看；现代含义可理解为便于携带的、听得见的、看得见的，需核对具体用法。
2. 同形词或不同义项可能有不同来源、发展和专业含义。
3. 例如 We need to inspect the output. 用自己的对象替换，并保持自然搭配。

</details>
