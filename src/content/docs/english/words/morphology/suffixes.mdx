## 先区分派生与屈折

help → helpful 形成相关的形容词；work → worked 通常是同一动词的过去形式。前者属于派生，后者属于屈折。两者都会影响词尾，但解决的不是同一个问题。

| 目标词类 | 常见后缀 | 例子 |
| --- | --- | --- |
| 名词：过程、结果 | -tion / -sion、-ment | action、decision、development |
| 名词：性质、状态 | -ness、-ity | kindness、security |
| 名词：人或角色 | -er / -or、-ist | teacher、actor、scientist |
| 形容词：可……的 | -able / -ible | readable、accessible |
| 形容词：具有 / 缺少 | -ful / -less | helpful、careless |
| 形容词：性质或关联 | -al、-ive、-ous、-ic | personal、active、dangerous、basic |
| 动词 | -ize / -ise、-ify、-en | organize / organise、simplify、widen |
| 副词 | 常见 -ly | carefully、clearly |

这张表只表示常见线索。friendly 是形容词；fast 可以直接作副词。-er 也可能是比较级，不一定表示一个人。

## 词性变化会带来拼写调整

happy → happiness / happily：部分辅音字母 + y 结尾的词会改 y 为 i；create → creation 涉及词尾变化；simple → simplify 不能当作完整词加 -ify 的无变化拼接。规则可以辅助，但要把词族实际形式写出来。

helpful 的 -ful 只有一个 l；carefully 中 care + ful + ly 出现两个相邻 l。词尾不是看着像就随意加减。

## 用一个词族练不同句位

**We developed the tool.** develop 是动作。

**The development took months.** development 作名词主语。

**It is a useful tool.** useful 修饰名词；**Use it carefully.** carefully 修饰使用方式。

## 练习

1. “解释很清楚”选 clear 还是 clearly：The explanation is ___.
2. “她解释得很清楚”：She explained it ___.
3. helpful 与 helped 分别主要展示哪类词尾变化？

<details>
<summary>答案与解释</summary>

1. clear，表语描述 explanation。
2. clearly，修饰解释这一动作。
3. helpful 是派生出形容词；helped 在普通动词用法中是屈折形式，具体句中也可能参与分词结构。

</details>
