## 前缀提供线索，不自动给出完整词义

**reconnect = re- + connect** 很透明；但看到相同字母开头，不能就判断都是同一个前缀。in- 在 incorrect 中表示否定，在 inspect 的历史来源里与“向内”有关。

| 关系 | 常见前缀 | 词例与核心线索 |
| --- | --- | --- |
| 否定 | un-、non- | unsafe、nonverbal：不、非 |
| 否定的不同形式 | in- / im- / il- / ir- | inaccurate、impossible、illegal、irregular |
| 反向、分离或否定 | dis-、de- | disconnect、decode：具体意义看词 |
| 错误 | mis- | misunderstand、misread |
| 再次 | re- | review、rewrite、reconnect |
| 之前 / 之后 | pre- / post- | preview、postgraduate |
| 过度 / 不足 | over- / under- | overwork、underestimate |
| 之间 / 内部 | inter- / intra- | international、intranet |
| 下方 / 更高层级等 | sub- / super- | submarine、superhuman |
| 跨越 | trans- | transport、transcontinental |
| 共同 | co- | cooperate、coauthor |
| 单 / 双 / 多 | mono- / bi- / multi- | monolingual、bilingual、multilingual |
| 反对、抵抗 | anti- | antivirus、antiwar |

**un- 与 dis- 不能自由替换。** 具体选哪个要记词。in- 的同化形式提供拼写线索，但也不是凭下一个字母就可以创造任意新词。

## 一组词，建立两个方向

connect → disconnect → reconnect。先说动作链：建立连接 → 断开 → 再连接；再造句：**The call disconnected, so I reconnected.** 词缀、画面和语境共同形成联系。

**uninterested** 常指没有兴趣；**disinterested** 在正式用法中常指公正、不偏私，实际也有其他使用。这说明看见否定前缀后，仍需查词典的义项与语域。

## 学习时记录什么

记录基本词、前缀线索、当前含义、一个搭配和一个对照词。不要只背“re=再”，却没有任何能使用的句子。

## 练习

1. 用 rewrite、preview、misunderstand 各解释前缀提供了什么线索。
2. “重新连接网络”如何表达？
3. 能否根据 in- 永远等于“不”推断 inspect？

<details>
<summary>答案与解释</summary>

1. 再写、提前查看、理解错误。现代含义仍以实际用法为准。
2. reconnect to the network。
3. 不能。同形字母或历史前缀可能承担不同意义。

</details>
