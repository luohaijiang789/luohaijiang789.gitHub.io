## 本组怎样记

用搬运、拉动、投放与传递的动作线索记住现代搭配。 先看每个动作或概念，再比较词性、搭配和现代含义。下图使用历史来源作为记忆线索，不把它当成可以机械拼词的万能公式。

## port：运输与便携

transport equipment 表示运送设备；a portable device 描述便携设备。portable 是形容词，不直接代替运输动作。图像里可以是一辆搬运箱子的车，也可以是能轻松带走的小设备。

## tract：拉近与拉出

attract attention 表示吸引注意；extract data 表示提取数据。方向画面是记忆线索，现代 extract 还会出现在其他专业语境里。先记一组熟悉的对象，之后再扩展。

## ject：注入与拒绝

inject data 与 reject a request 都常见于技术表达。reject 表示拒绝请求，不等于已经解释了拒绝原因。构句时继续写依据：The system rejected the request because the token had expired.

<WordMeaningMap name="root-ject" />

## mit / miss：传输与发出

transmit a signal 强调传递信号，emit light 表示发光。它们有送出、放出的历史联系，但现代用法不任意互换。具体专业对象应在实际资料里继续核对。

## 练习

把“吸引注意、提取数据、拒绝请求、传输信号”各写成一个英文语块。再选择一个语块扩写成带原因的句子。

<details>
<summary>答案与解释</summary>

attract attention；extract data；reject a request；transmit a signal。例如 The system rejected the request because the user lacked permission. 依据应和实际情境一致。
