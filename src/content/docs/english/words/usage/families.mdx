## 用形式、意义与句位连接一个词族

以 decide 为中心：decide（作决定）→ decision（决定）→ decisive（果断的或决定性的）。它们相关，却不能放在同一个句位里随意替换。

| 需要表达什么 | 合适形式 |
| --- | --- |
| 我们需要决定 | We need to decide. |
| 这是一个重要决定 | This is an important decision. |
| 这个因素起决定作用 | This is a decisive factor. |

**词族不是同义词表。** decisive 的含义不等于“所有与决定相关的形容词”。把现代用法与搭配核验清楚。

## 一词多义依赖场景

run 可以跑步、运行程序或经营业务：run a test、run a company。issue 可以是问题，也能作动词表示发布等。charge 可能涉及收费、充电、指控等，不能看到一个熟悉中文义就忽略对象与句法。

从高频当前义项开始，再用对比例句扩展。每次新义都写清：词性、对象、搭配和场景。

## 转换与合成

email 可以作名词或动词：Send an email / Email me。词类变化不一定出现后缀。

合成词把已有成分组合：password、workplace、time-consuming。写成一个词、两个词或加连字符常有词典或风格习惯，不自行假定所有组合都一样。

## 用网络组织，而不是只记箭头

```text
work
├─ a job / a task：比较“职位”和“具体任务”
├─ work on a project：在做哪个项目
├─ work with a team：与谁协作
├─ workplace / teamwork：合成词
└─ workable：可行的，与“正在工作”不同
```

## 练习

1. decision 能否直接放在 We need to ___ 的空格里？
2. “运行一次测试”中 run 的含义是什么？
3. 为自己常用的一个词写三个不同搭配，而不只写三个中文义。

<details>
<summary>答案与解释</summary>

1. 不能直接这样代替动词；可说 We need to decide，或 We need to make a decision。
2. 执行或开展测试，不是身体跑步。
3. 例如 access a file / have access to a file / restrict access。注意词性与介词。

</details>
