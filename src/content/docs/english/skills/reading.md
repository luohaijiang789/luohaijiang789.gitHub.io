## 第一遍找任务，第二遍找结构

读说明文先问：这篇在解释原理、比较方案，还是报告结果？再找每段的中心句、原因、例子与限制。需要精确操作的文档，要特别关注前提、否定词、范围和警告。

## 原创阅读材料

**A permission check is useful only if it is applied at the right boundary. A model may suggest an action, but that suggestion does not establish the user's authority. The application must evaluate the request using trusted information. This reduces one class of unauthorized actions; it does not eliminate every risk in an AI system.**

```text
中心判断：检查要位于正确边界
    ├─ 对比：模型提出建议 ≠ 建立用户权限
    ├─ 行动：应用使用可信信息检查
    └─ 边界：减少一类风险 ≠ 消除全部风险
```

## 先找主干，再看附加信息

**A permission check / is useful / only if it is applied at the right boundary.** 句子主干为检查是有用的，only if 限制这个判断的成立条件。

but、however 常提示转折；because、therefore 涉及原因与结果；for example 引入例子；may、some、only、not every 限定论断力度。它们常比一个不认识的普通名词更影响整体理解。

## 生词处理分层

不影响主旨的词可以暂记；决定动作或判断的关键词要核验；重复出现的术语应建立定义。词根、上下文与词性帮助提出猜测，不能代替最终核对。

代词 this、it、they 的指向要找得到。句子中的 this reduces 指前面的授权检查做法，不是任意最近的单个名词。

## 练习

1. 用一句中文概括材料。
2. 原文是否宣称彻底解决 AI 系统风险？
3. only if 限制了哪个判断？

<details><summary>答案与解释</summary>

1. 模型建议不等于权限，应用需要在正确边界用可信信息检查，同时保留风险范围的说明。
2. 没有，最后一句明确限制为一类风险。
3. 检查的有用性与是否应用在正确边界相联系。

</details>
