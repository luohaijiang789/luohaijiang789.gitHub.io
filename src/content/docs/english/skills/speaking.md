## 三个目标分开检查

**可懂度：** 别人能否听懂你的词和重点？**准确性：** 时间、对象和逻辑是否表达对？**流畅度：** 能否在合理停顿中继续表达？三者相关，但不应只用语速衡量。

## 练一个场景的三轮

第一轮跟读一句，模仿重音和停顿。第二轮遮住文本，表达相同意思，允许用更简单的词。第三轮改变人物、时间和对象，完成自己的版本。

**示范：** I checked the logs and found an invalid token. I haven't confirmed the cause yet. Next, I'll compare the request with a successful one.

先说观察、再说不确定、最后给行动。若只背下示范句，换个问题就无法继续，说明还需要迁移练习。

## 卡住时怎样继续

| 情况 | 可以怎样做 |
| --- | --- |
| 想不起专业词 | 描述用途：the tool we use to… |
| 需要思考 | Let me think for a moment. |
| 发现说错 | Let me correct that. I meant… |
| 对方没懂 | Let me put it another way. |
| 想确认问题 | Are you asking about…? |

这些表达帮助维持对话，但不能替代必要信息。纠正时说清改的是时间、数字还是结论。

## 一分钟项目介绍

问题约一句，自己的行动约两句，证据与局限各一句。用真实信息：**The problem was… / I built… / I tested… / One limitation is…**。请别人用自己的话复述；若重点丢失，先修改结构，再追求更复杂词汇。

## 练习

录下一个不超过一分钟的解释。听回时只选两件事修改：一个影响理解的发音或语法问题，一个信息组织问题。再录一次比较。
