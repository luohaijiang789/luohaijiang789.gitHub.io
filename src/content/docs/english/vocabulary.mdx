## 这些入口分别解决什么问题

| 入口 | 帮助建立的联系 | 如何检验 |
| --- | --- | --- |
| 词根词缀 | 形式与含义之间的关系 | 能解释构词线索，也能理解实际例句 |
| 图像记忆 | 动作、空间和概念 | 不看词，能否从画面想起表达 |
| 联想故事 | 与熟悉人物或经历的关系 | 下一次遇到时，是否能借线索回忆 |
| 关联与辨析 | 词族、搭配、相近词的区别 | 换一种词性或对象后，能否用对 |
| 场景搭配 | 谁在什么情况下怎样说 | 替换时间、地点或对象后再说一次 |
| 主动回忆 | 从线索提取自己的表达 | 先作答，再看参考，安排以后重练 |

## 积累自己的例句

“我的记忆线索与例句”可以记录你自己的画面、容易混淆的地方、好用的方法和真实造句。比如学习 available 后，写一个你真的想约的时间。

构词来源链接位于每个词的“词根词缀”页。inspect、predict、transport 使用词典记录的历史来源作为线索；图像和故事是本站为学习设计的联想。

理解各方法的适用范围，见[方法与证据](/english/methods/)。
