## 单词内部有重音

词典 /əˈbaʊt/ 的 ˈ 指明主要重音。重读音节通常更突出，非重读音节可能缩短或弱化。不要用“哪个字母看起来重要”决定重音。

有些词的重音与词性有关：record 作名词与作动词时，常见重音位置不同。后缀也可能影响重音，如部分 -tion、-ic 词有常见模式，但新词仍要查证，不能按后缀一律推算。

## 一句话突出什么，表达就偏向什么

看这句话：**I sent the report yesterday.**

| 突出的词 | 可能在回答什么 |
| --- | --- |
| I | 谁发的？是我。 |
| sent | 发了吗，还是只写好了？已经发了。 |
| report | 发的是报告，不是其他东西。 |
| yesterday | 什么时候发的？昨天。 |

具体意思依赖对话。先想“对方缺什么信息”，再决定重点；不要用机械固定规则取代实际意图。

## 功能词常见弱读

to、and、can 等在非强调位置常弱化；当它们需要对比、强调或单独出现时，又可能使用强读形式。比如 can 在 “Yes, I can.” 与流畅陈述句中，突出程度可能不同。

```text
先分意群：  I checked the logs | and found a problem.
再找重点：       checked / logs        found / problem
最后连接：  非重点词更轻，重点信息更清楚。
```

不要为了模仿快语速，把自己还没有理解的词全部吞掉。先保证可懂度，再逐步调整节奏。

## 练习

1. 同一句 “I need the file today.” 分别强调 file 和 today，说出各自情境。
2. 为什么 can 不能永远都弱读？
3. 朗读一段自己的项目介绍，用竖线标出意群，再请别人复述重点。

<details><summary>答案与解释</summary>

1. 强调 file 可以区分需要的对象；强调 today 可以突出截止时间。
2. 对比、纠正、单独回答等情况下，它可能需要承载重点。
3. 别人能否抓住核心信息，比每个词是否同样清楚更能反映表达效果。

</details>
