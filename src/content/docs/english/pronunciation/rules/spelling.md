## 拼读是推测工具

英语拼写保留了不同历史层次。常见模式可以减少记忆负担，但不能保证“看见一个组合就只有一种读法”。把规则、词例与例外同时记录。

| 模式 | 常见例子 | 需要一起记住的边界 |
| --- | --- | --- |
| 辅音—元音—辅音的短词 | cat、sit、hop | 是学习模式，不涵盖所有封闭音节 |
| 元音 + 辅音 + 不发音 e | cap → cape；kit → kite | have、give 不能按同一读法猜 |
| ee、ea | see、team 常含 /iː/ | head、great 的 ea 不同 |
| ai、ay | rain、day 常含 /eɪ/ | 仍需查具体词 |
| sh、ch、th | ship、chair、thin / this | ch 在 school、chef 中读音不同；th 有清浊 |
| c 在 e/i/y 前 | city、cent 常读 /s/ | 不是无例外定律 |
| g 在 e/i/y 前 | giant、general 常读 /dʒ/ | get、give 常读 /ɡ/ |
| 不发音的字母 | know 的 k；receipt 的 p | 不要把不发音字母删出拼写记忆 |

## 音节、字母组合和词素不要混成一件事

unhelpful 可以按词素看成 un- + help + -ful；按声音则有音节和重音。这两种分法回答不同问题：构词解释结构，音节帮助发音。词根的边界未必就是音节边界。

## 遇到新词时的顺序

先认熟悉的词缀或组合 → 根据模式猜读音 → 查词典的当前词性与口音 → 标重音 → 连同搭配记忆。遇到例外就保存整个词，不再为它编造一条牵强的新规则。

例如 live 作动词与某些形容词用法时读音不同；read 的现在式与过去式拼写相同，读音不同。单靠拼写无法决定，必须看语法与上下文。

## 练习

1. cap 与 cape 的元音通常有什么变化？
2. team、head、great 能否用“ea 永远一个读音”解释？
3. “I read the report yesterday.” 中 read 与一般现在式的读音相同吗？

<details><summary>答案与解释</summary>

1. 常见对比为 /æ/ 与 /eɪ/。
2. 不能，这三个词的 ea 通常分别对应 /iː/、/e/（有些标法 /ɛ/）、/eɪ/。
3. 不同。这里是过去时间，read 读 /red/；一般现在式通常读 /riːd/。

</details>
