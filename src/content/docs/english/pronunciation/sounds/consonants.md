## 用三个问题描述一个辅音

声带是否振动？气流在哪里受阻？是先堵住再释放，还是持续摩擦？把动作想清楚，比用汉字谐音标注更可迁移。

| 类别 | 常见音 | 动作与提示 |
| --- | --- | --- |
| 塞音 | /p b t d k ɡ/ | 短暂阻塞，再释放；不要每个尾音后都添“呃” |
| 摩擦音 | /f v θ ð s z ʃ ʒ h/ | 气流经过收窄处；部分音可持续 |
| 塞擦音 | /tʃ dʒ/ | 堵住后以摩擦释放，如 chair / judge |
| 鼻音 | /m n ŋ/ | 气流通过鼻腔；sing 末尾通常不再加 /ɡ/ |
| 近音 | /l r w j/（具体标法依词典） | 控制舌位和嘴唇，保持元音连接 |

## 四组高价值对比

**/v/ 与 /w/**：/v/ 是上齿与下唇附近的摩擦；/w/ 通常由圆唇开始，没有同样的唇齿摩擦。练 vest / west。

**/θ/ 与 /s/**：/θ/ 的舌尖靠近或轻触上齿，气流从间隙经过；/s/ 不把舌尖伸到同样位置。练 thin / sin。/ð/ 如 this 带声带振动，不等同 /z/。

**/l/ 与 /r/**：light / right 的区别涉及舌位。不同口音的 /r/ 实现方式不完全相同，不必强求一种固定卷舌程度。

**/n/ 与 /ŋ/**：sin 与 sing。后者舌后部靠近软腭，而不是把 /n/ 后机械补成“格”。

## 尾音不能一律丢掉

cap / cat / cash 在尾辅音上区分词义。尾塞音在自然语流中可能没有明显爆破，但不意味着可以随意删去。先慢读保留对比，再进入句子。

speak、next、tasks 等组合也不要添额外音节。可先分段慢练 /s/ + /piːk/，逐渐连接。

## 练习

1. 判断 /f/ 与 /v/ 哪个带声带振动。
2. 朗读 “We reviewed the very old version.”，检查 /w/ 与 /v/。
3. 把 “I need a cap” 和 “I need a cat” 分别说给别人听，请对方辨认。

<details><summary>答案与解释</summary>

1. /v/ 是浊音；轻触喉部可以辅助感受振动，但最终要核对实际声音。
2. we 起始 /w/；very、version 起始 /v/。重点是动作区别，而不只是嘴唇看起来是否圆。
3. 如果对方无法区分，回到尾音练习。不要为了强调尾音再加一个元音音节。

</details>
