## 先确认广告里没有说清的内容

room、flat / apartment、rent、deposit、utilities、furnished、viewing、repair 是这一情境的核心词。不同地区用词和实际流程可能不同，语言课不把某个地区的条件当成统一规则。

| 需求 | 问法 |
| --- | --- |
| 是否仍可租 | Is the room still available? |
| 看房 | Could we arrange a viewing? |
| 哪些费用包含 | Which bills are included in the rent? |
| 押金金额 | How much is the deposit? |
| 家具与设施 | Is the apartment furnished? |
| 搬入时间 | When would I be able to move in? |

## 对话：确认费用

**You:** Are utilities included in the rent?

**Host:** Some of them are.

**You:** Could you clarify which ones? Does that include electricity and internet?

**Host:** Internet is included, but electricity is separate.

**You:** So the rent includes internet, and I pay for electricity separately. Is that right?

“Some” 没有说明到底哪些。继续具体化，再复述条件；书面材料中的费用仍需逐项核对。

## 报修：事实、影响与时间

**The heating in my room isn't working. It stopped last night. Could someone take a look? When should I expect an update?**

描述哪件设施、什么表现、什么时候开始、影响是什么。先用可观察事实，不擅自断定技术原因。

**There is a leak under the sink.** there 引入新问题；**The sink is leaking.** 直接描述设施状态。把语法与当前沟通目的连接。

## 练习

1. 对方说 bills included，追问究竟包含什么。
2. 写三句报修邮件，说明房间灯昨天开始不亮。
3. 约周六看房，并询问对方有空的具体时间。
