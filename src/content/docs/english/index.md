目标是逐步做到：听懂同事的问题、解释自己的工作、提出清楚的问题，以及独立处理海外生活中的交流。

## 每个场景的学习过程

**看图理解 → 听读输入 → 拆解表达 → 遮挡回忆 → 换情境使用 → 间隔复习**

| 学习方法 | 适合怎样使用 | 需要避免的误区 |
| --- | --- | --- |
| 场景与图像 | 记住人物、动作、对象和表达意图 | 图片与词义无关，只是好看 |
| 常用语块 | 连同搭配一起学，如 have permission to | 认识每个单词，却组不成自然的表达 |
| 词根词缀 | 用可靠构词关系组织词族 | 牵强拆词，或者把拆解当成完整词义 |
| 跟读与复述 | 先模仿短句，再脱稿表达同一意思 | 只反复播放，没有主动输出 |
| 主动回忆 | 先看中文情境或图片，再说英文 | 一直看答案，误以为自己记住了 |
| 间隔练习 | 在后续几天重新回忆并实际使用 | 只在学习当天集中重复 |

这些方法是互补的。选择能帮助当前内容理解与使用的方法，再根据自己的表现调整。

## 之后怎样扩展

优先补充与你的实际目标接近的场景：介绍项目、代码评审、请求帮助、技术面试、与招聘者交流。海外生活再增加租房、看病、开户和处理误会。

每个场景先控制在少量核心表达，练到能够换词复用，再继续扩展。
