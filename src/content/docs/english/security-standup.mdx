## 先理解这段对话

| 人物 | 英文 | 理解重点 |
| --- | --- | --- |
| Maya | What happened with the agent? | 想知道发生了什么 |
| You | It tried to read a private file. | tried to：尝试做；不代表已经成功 |
| You | The policy gate blocked the request. | 明确是谁阻止了什么 |
| Maya | Do we know why it made that request? | 继续追问原因 |
| You | Not yet. Let’s check the logs first. | 不确定就说明不确定，并提出下一步 |

**句子骨架：** 谁 + 做了什么 + 对什么对象。先用短句说准确，再练习连接。

## 用图像与搭配记住词

| 词或语块 | 画面联想 | 常用表达 |
| --- | --- | --- |
| request | 智能体递出一张访问申请单 | make a request / block a request |
| permission | 门口核验“能否进入”的通行许可 | have permission to read a file |
| access | 从门外接触或使用里面的资源 | access a file / have access to a system |
| clarify | 把模糊的图擦清楚 | clarify a requirement / clarify what you mean |
| investigate | 顺着日志线索逐步查明情况 | investigate an alert / investigate the cause |

图像是帮助回忆的联想，不是词源解释。注意：access 作动词时可以直接接对象；名词搭配常见 **access to**。

## 用词族连接表达

<WordFamily />

把词族与词性一起记。**-ify** 常见于表示“使……化”的动词，如 simplify；**-ation** 常见于名词，但不能据此机械推导所有单词的形式与含义。

在当前场景，优先掌握 **Could you clarify…?** 和 **have permission to…**，不必一次记完所有派生词。

## 礼貌地把问题问具体

- **Could you clarify what you mean by “access” here?** 请澄清这里的 access 指什么。
- **Do you mean the agent read the file, or only tried to read it?** 你说的是已经读取，还是仅尝试读取？
- **My understanding is that the request was blocked. Is that correct?** 我理解请求被拦截了，这样理解对吗？

## 三轮输出练习

1. **有提示：** 看图，说出 agent、private file、policy gate 之间发生了什么。
2. **无文本：** 遮住英文，解释事实与下一步。可以短暂停顿，不要求逐字复现。
3. **换场景：** 把 read a private file 换成 update a team note；把 check the logs 换成 review the access policy。

## 怎样判断自己学会了

- 能区分 tried to 与实际成功完成。
- 能说清主体、动作和对象。
- 不知道原因时，能承认不确定并提出下一步。
- 第二天不看答案，也能表达相同意思。
