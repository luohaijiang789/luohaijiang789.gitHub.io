把思考与表达放在实际工作里练：排查故障、讨论设计、解释风险、提出请求、面对不同意见。

## 四组练习

| 能力 | 练习问题 | 成果 |
| --- | --- | --- |
| 分析与判断 | 这是事实、推测，还是结论？ | 证据与假设清单 |
| 提问与澄清 | 对方说的“安全”“完成”具体指什么？ | 有边界、能回答的问题 |
| 组织与解释 | 对方需要理解什么，才能决定下一步？ | 一分钟说明与一页图解 |
| 沟通与协作 | 我的诉求、理由和可选方案是什么？ | 场景表达与使用后的复盘 |

## 场景表达怎么记录

每条表达都附上：情境、对象、目的、说法、语气与后果。比如表达不同意见：

> 我担心这个方案仍然允许越权读取。我们能否先验证资源权限，再考虑自动执行？

> I’m concerned that this could still allow unauthorized reads. Could we verify the resource permissions before enabling automatic execution?

先指向具体问题，再给出可讨论的行动。使用后记录对方是否理解，以及下一次怎样改进。
