从能解释一个具体系统开始，逐步建立网络、操作系统、编程与软件工程的知识。

## 先走通一个最小系统

| 主题 | 需要回答的问题 | 练习成果 |
| --- | --- | --- |
| 网络与 HTTP | 请求怎样到达服务，谁决定能否访问？ | 请求流程图与一次抓包记录 |
| Linux 与进程 | 程序在哪里运行，拥有谁的权限？ | 进程、文件权限与日志排查记录 |
| Python / JavaScript | 如何把检查规则写成程序？ | 一个可运行的小工具与边界测试 |
| 工程实践 | 别人怎样重复我的结果？ | Git 历史、README、依赖与自动化测试 |
| AI 基础 | 模型如何接收上下文，如何提出工具调用？ | 一份输入、输出与执行链路图 |

## 从这里开始

[图解：一次 HTTP 请求与权限检查](/foundations/http/)

学完后进入[智能体工具调用](/security/tool-boundaries/)。每次只补当前实验缺少的一块基础，逐步扩展这张地图。

## 学习记录建议

保留环境、操作、预期、实际结果、原因与后续问题。遇到报错时先读原始输出，再形成假设，最后用一次有区分度的实验验证。
