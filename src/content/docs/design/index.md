先从与你的专业表达最接近的作品练起：技术图解、项目页面、简历与演示文稿，再扩展到摄影和其他视觉创作。

## 每次收藏，多做一步

| 观察对象 | 提问 | 动手练习 |
| --- | --- | --- |
| 排版 | 哪个信息最先被看见？ | 用字号、间距和对齐重做一页 |
| 配色 | 颜色在提示什么含义？ | 限制为一个主色与少量语义色 |
| 技术图解 | 流向与边界是否清楚？ | 重画一张自己项目的流程图 |
| 摄影 | 主体、光线与背景怎样配合？ | 同一主体尝试三种构图并比较 |
| 演示文稿 | 一页需要观众记住什么？ | 删除不支持核心结论的元素 |
